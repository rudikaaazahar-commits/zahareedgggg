# Новорічний годинник

Адаптивний україномовний сайт із відліком до найближчої новорічної опівночі. Сайт можна встановити на телефон як PWA, якщо хостинг це підтримує.

## Опублікувати на GitHub Pages

У репозиторії відкрийте **Settings → Pages → Build and deployment**, виберіть **Deploy from a branch**, гілку `main` і папку `/(root)`, потім натисніть **Save**. Дочекайтеся публікації та відкрийте адресу, яку покаже GitHub Pages. Для встановлення та дозволу сповіщень потрібен HTTPS.

## Сповіщення на телефоні

Натисніть **«Увімкнути сповіщення»** та дозвольте їх у браузері. У браузері, який це підтримує, сайт покаже системне повідомлення при настанні Нового року, поки сторінка відкрита або браузер не призупинив її.

Статичний сайт на GitHub Pages не має push-сервера: він не може гарантувати сповіщення, якщо браузер повністю закритий або система зупинила сайт. Для надійного фонового push-сповіщення потрібен окремий push-сервіс і серверна інфраструктура. На iPhone системні web push-сповіщення для вебзастосунків зазвичай потребують додавання сайту на головний екран і надання дозволу.
