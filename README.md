# Зберіть Україну

Повноцінна браузерна аркада українською мовою.

- Ловіть жовті зірки для отримання очок.
- Уникайте темних хмар.
- У вас є три життя та 45 секунд.
- Рекорд зберігається в браузері.
- Підтримка клавіатури та сенсорних пристроїв.

## Керування

- Клавіатура: `←` `→` або `A` `D`.
- Телефон/планшет: кнопки зі стрілками внизу екрана.

## Запуск

Відкрийте `index.html` у браузері або увімкніть GitHub Pages у налаштуваннях репозиторію: **Settings → Pages → Deploy from a branch → main → /(root)**.
